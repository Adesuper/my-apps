🧰 Before you start (one evening, a parent)

You need
  • The Freenove Raspberry Pi 4 kit you have (Pi, breadboard, wires, LEDs, sensors).
  • A microSD card with Raspberry Pi OS (the normal version with the desktop).
  • A screen (TV or monitor with micro-HDMI cable), keyboard and mouse.
  • The official Pi power supply.
  • Home Wi-Fi.
Check the Freenove box for these
  • LEDs (red + another colour) and 220 Ω resistors
  • A push button
  • An active buzzer (and the small transistor the kit uses with it)
  • A PIR motion sensor (HC-SR501, white dome)
  • A DHT11 temperature & humidity sensor (blue)
  • An LCD1602 screen with an I2C board (4 pins)

Missing one? It's in the shopping list under Level 1, and it's cheap.

1. Get the Pi ready (type in the Terminal)

sudo apt update && sudo apt full-upgrade -y sudo raspi-config # Interface Options → I2C → Yes (for the LCD screen) mkdir ~/buildlab && cd ~/buildlab

2. Download all the programs onto the Pi

cd ~/buildlab for f in s1_blink s2_doorbell s3_motion_alarm s4_room_screen s5_smart_room car_dance car_guard israel_phone; do wget -q https://adesuper.github.io/my-apps/build-lab/code/$f.py done ls

3. Copy two helper files from the Freenove kit

The kit's own code folder has LCD1602.py (in the I2C LCD1602 lesson) and Freenove_DHT.py (in the DHT11 lesson). Copy both into ~/buildlab. Sessions 4 and 5 need them.

Safety rules (read them together):
  1. Power OFF the Pi before changing any wire.
  2. A parent checks the wiring before the power goes back on.
  3. Never connect 5V straight to GND, and never connect a pin to 5V.
  4. Nothing that plugs into a wall socket ever touches the breadboard.
  5. The car batteries (Level 2) are only charged with their charger, with an adult around.

The Pi's pins: everything Level 1 uses

The 40 pins are numbered by position (1 to 40). The code uses the GPIO number. Pin 1 is the corner pin with the square solder pad, closest to the SD card side.

🏠 Level 1 · Smart Room

Five sessions. Each one adds a new part, and all five come together in session 5, where a phone controls his room. Cost: $0 with the Freenove kit.

🚗 Level 2 · Robot car

The Freenove 4WD Smart Car Kit for Raspberry Pi uses the Pi you already have. Freenove's own tutorial (a PDF and code on their website and GitHub) is excellent: follow it for building and testing. This guide tells you which part to do each session and adds Israël's own programs.

Before ordering: the car needs 2 rechargeable 18650 batteries, which are not included in the kit, plus a charger for them. Order them at the same time.
The car uses the Pi from his Freenove kit. While the Pi is on the car, the Smart Room is "off". That's fine, or see Level 3 for a second Pi.

📱 Level 3 · The Israël Phone

A handheld touchscreen computer with a camera and apps he programs himself. It can't make phone calls (that needs a phone company SIM card and is very complicated), but everything else is his.

Recommended: a second Raspberry Pi for this level, so the robot car keeps its Pi. Without it, you can move the Pi from the car to the phone, but he can't use both at once.

🌱 Bonus projects

For any time he wants a change. Tell me which one he picks and I'll write the step-by-step sessions and code for it.

🌱 The plant that waters itself

A soil sensor checks if the plant is thirsty. If it is, a tiny pump gives it water, and the Smart Room page says "I'm thirsty!" Great link with his science unit (the water cycle).

Buy: capacitive soil sensors, a mini 5V pump with tubing and a relay module, a small pot. The Freenove kit's ADC module reads the soil sensor (the Pi can't read it alone).

🌦️ Weather station

Uses the DHT11 from Level 1, plus a pressure sensor. It records every 10 minutes and draws a chart on the phone. Compare it each morning with the weather forecast: who was right?

Buy (optional): a BMP280 pressure sensor.

🕹️ Retro game console

Install RetroPie on a microSD card, plug in a USB controller and play classic games he's allowed to. Less building, more playing: a nice reward after Level 2.

Buy: a USB game controller and a spare microSD card.

🆘 When something doesn't work

ProblemTry this
The LED doesn't lightTurn the LED around: the long leg goes towards the GPIO pin. Check the resistor is in the same breadboard row.
GPIO busy or pin already in useAnother program is still running. Close it (Ctrl + C) or restart the Pi.
The buzzer is very quiet or silentBuild it with the small transistor, the way the kit's buzzer lesson shows. Check that it's the active buzzer (it has a sticker on top).
The motion sensor goes off all the timeWait the full 30 seconds of warm-up. Turn the sensitivity knob down. Keep it away from heaters and windows.
The LCD lights up but shows nothingTurn the small blue knob on the back (contrast). Check the address with i2cdetect -y 1 and put it in the code (0x27 or 0x3f).
No module named LCD1602 (or Freenove_DHT)Copy that file from the Freenove kit's code folder into ~/buildlab.
The temperature says "Sensor busy" foreverCheck the DHT11 wire on GPIO23 (pin 16). Read step 4 at the top of s4_room_screen.py about the pin number.
The phone can't open the Smart Room pageThe phone must be on the same Wi-Fi as the Pi. Use the address from hostname -I and add :5000. The program must still be running on the Pi.
The car turns the wrong waySwap the + and − in spin_left and spin_right. Re-check the motor wires against the kit's tutorial.
The camera isn't foundPower off and check the ribbon cable: the right way round, pushed all the way in, latch closed. Then test with rpicam-hello.
