SKILL 1

🗣️ print( ) — make the computer talk

print shows a message on the screen. The words go inside quotes.

print("Hello! I am learning Python.")
Hello! I am learning Python.
SKILL 2

📦 Variables — boxes that remember

A variable is a labelled box that holds a value so you can use it later. You make one with an = sign.

# put values into boxes named score and name
score = 100
name  = "Alex"
print(name)
print(score)
Alex 100

Now the computer remembers those values. You can change them any time.

SKILL 3 — THE BIG ONE

⌨️ input( ) and the sneaky trap

input asks the user to type something. Here's the trap that fools almost everyone:

input() ALWAYS gives you text — even when you type numbers!

So if you try to add two inputs, Python glues the text together instead of adding:

a = input("First number: ")   # you type 5
b = input("Second number: ")  # you type 5
print(a + b)
55 <-- oops! it stuck "5" and "5" together, not 5 + 5

The fix: wrap the input in int( ) to turn the text into a real number first. 🔑

a = int(input("First number: "))   # now it's a number
b = int(input("Second number: "))
print(a + b)
10 <-- yes! real math now
💡 Remember this rule and you'll never be stuck on a calculator program: numbers from input() need int() around them.
SKILL 4

➕ The math operators

Python does arithmetic with these symbols:

+   add          7 + 2  = 9
-   subtract     7 - 2  = 5
*   multiply     7 * 2  = 14
/   divide       7 / 2  = 3.5
//  divide, whole number only   7 // 2 = 3
%   remainder (what's left over) 7 % 2  = 1
🍕 See // and %? That's the exact "each gets…" and "leftover…" from your division homework — now the computer does it for you!
SKILL 5

✨ f-strings — put a value inside a sentence

Start the quotes with f, then drop a variable inside { }. Super handy.

name = "Alex"
age  = 9
print(f"Hi {name}, next year you'll be {age + 1}!")
Hi Alex, next year you'll be 10!
