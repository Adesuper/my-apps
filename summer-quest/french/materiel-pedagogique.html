1 📛 Le nom

🎯 Objectif : reconnaître un nom, distinguer nom commun / nom propre, et dire son genre (m./f.) et son nombre (sing./plur.).

La règle

Un nom désigne une personne, un animal, une chose ou une idée. Le nom commun est général (un chien, une ville) ; le nom propre désigne quelqu'un ou quelque chose de précis et prend une majuscule (Léo, Montréal). Le genre = masculin ou féminin. Le nombre = singulier (un) ou pluriel (plusieurs).

Au tableau

Le petit chien de Léa dort.
→ chien = nom commun, masculin, singulier · Léa = nom propre (majuscule)
✏️ Activité guidée : dans le journal ou un livre, surligne 5 noms. Pour chacun, dis à voix haute : commun ou propre ? masculin ou féminin ? singulier ou pluriel ?

Exercices

  1. Souligne les noms : « La maîtresse raconte une histoire aux enfants. »
  2. Nom commun ou propre ? a) Québec b) rivière c) Amélie
  3. Genre ? a) une chaise b) un ballon c) une pomme
  4. Singulier ou pluriel ? a) des livres b) un oiseau c) les maisons
Voir le corrigé

1. maîtresse, histoire, enfants. 2. a) propre b) commun c) propre. 3. a) féminin b) masculin c) féminin. 4. a) pluriel b) singulier c) pluriel.

▶ Pratique : sujet « Le nom »

2 🔖 Le déterminant

🎯 Objectif : repérer le déterminant devant le nom et choisir celui qui s'accorde (genre + nombre).

La règle

Le déterminant se place juste avant le nom et s'accorde avec lui : le, la, l', les, un, une, des, mon, ma, mes, ce, cette, ces…

Au tableau

une pomme (f. sing.) · un garçon (m. sing.) · des amis (plur.) · cette maison (on montre)
✏️ Activité guidée : je dis un nom, tu ajoutes deux déterminants possibles. Ex. « chat » → un chat, le chat, mon chat, ce chat.

Exercices — complète

  1. ___ école (f. sing.)
  2. ___ crayons (plur.)
  3. ___ soleil (m. sing.)
  4. ___ fleur, je la trouve belle (on montre, f. sing.)
Voir le corrigé

1. une (ou l', mon…) 2. des (ou les, mes…) 3. le (ou un, ce…) 4. cette.

▶ Pratique : sujet « Le déterminant »

3 ✨ L'adjectif & l'accord

🎯 Objectif : reconnaître l'adjectif, l'accorder avec le nom (genre + nombre), y compris après le verbe être.

La règle

L'adjectif décrit le nom. Il s'accorde avec lui : + e au féminin, + s au pluriel. Après le verbe être, l'adjectif s'accorde avec le sujet : « Elles sont contentes. »

Au tableau

un chat noir → une chatte noire → des chats noirs
Le chien est petit. → La chienne est petite. → Les chiennes sont petites.
✏️ Activité guidée : prends l'adjectif « vert ». Accorde-le avec : un vélo, une porte, des arbres, des feuilles. (vert, verte, verts, vertes)

Exercices — accorde l'adjectif

  1. une robe (rouge) ___
  2. des ballons (bleu) ___
  3. Elle est (gentil) ___.
  4. Les filles sont (grand) ___.
Voir le corrigé

1. rouge (invariable, finit déjà par -e) 2. bleus 3. gentille 4. grandes.

▶ Pratique : sujet « L'adjectif »

4 ♀️ Le féminin

🎯 Objectif : former le féminin — règle générale + terminaisons particulières + mots très différents.

La règle

Règle générale : on ajoute un -e (grand → grande).
Finit par…FémininExemple
-er-èrepremier → première
-eux-euseheureux → heureuse
-f-veneuf → neuve
consonne à doublerdouble + echat → chatte · bon → bonne
déjà -ene change pasrouge → rouge

Certains mots changent complètement : homme → femme, garçon → fille, roi → reine.

✏️ Activité guidée : « chasse au féminin ». Je dis le masculin, tu donnes le féminin le plus vite possible : petit, grand, sportif, premier, gentil.

Exercices — mets au féminin

  1. un ami → ___
  2. heureux → ___
  3. un chat → ___
  4. un homme → ___
  5. sportif → ___
Voir le corrigé

1. une amie 2. heureuse 3. une chatte 4. une femme 5. sportive.

▶ Pratique : sujet « Le féminin »

5 ♦️ Le pluriel

🎯 Objectif : former le pluriel — règle générale + terminaisons particulières.

La règle

Règle générale : on ajoute un -s (un chat → des chats).
Finit par…PlurielExemple
-s, -x, -zne change pasune souris → des souris
-au, -eau, -eu+ xun gâteau → des gâteaux · un jeu → des jeux
-al-auxun cheval → des chevaux
-oupresque tous + sun trou → des trous

7 mots en -ou prennent -x : bijou, caillou, chou, genou, hibou, joujou, pou → des genoux…

✏️ Activité guidée : trie 6 mots dans deux colonnes « + s » et « + x » : gâteau, ami, cheval (→ -aux), jeu, livre, oiseau.

Exercices — mets au pluriel

  1. un livre → ___
  2. un oiseau → ___
  3. un animal → ___
  4. une souris → ___
  5. un genou → ___
Voir le corrigé

1. des livres 2. des oiseaux 3. des animaux 4. des souris 5. des genoux.

▶ Pratique : sujet « Le pluriel »

6 👤 Les pronoms

🎯 Objectif : connaître les pronoms de conjugaison et remplacer un nom / un GN par le bon pronom.

La règle

Les pronoms de conjugaison : je, tu, il, elle, nous, vous, ils, elles. Un pronom remplace un nom ou un groupe du nom pour éviter de le répéter.

Au tableau

Léo court. → Il court. · Les filles chantent. → Elles chantent.
Maman et moi partons. → Nous partons. · Toi et Léa jouez. → Vous jouez.
✏️ Activité guidée : je dis une phrase avec un nom, tu la répètes avec un pronom. Ex. « Le chat dort. » → « Il dort. »

Exercices — remplace par un pronom

  1. Papa travaille. → ___ travaille.
  2. Les élèves lisent. → ___ lisent.
  3. Sara et moi mangeons. → ___ mangeons.
  4. La lune brille. → ___ brille.
Voir le corrigé

1. Il 2. Ils 3. Nous 4. Elle.

▶ Pratique : sujet « Les pronoms »

7 🧩 Le groupe du nom

🎯 Objectif : reconnaître un groupe du nom (GN) et faire tous les accords à l'intérieur.

La règle

Un groupe du nom = au minimum un déterminant + un nom, souvent avec un ou des adjectifs. Le nom est le noyau. Dans le GN, tout s'accorde avec le nom (genre + nombre).

Au tableau

un chien noir → des chiens noirs
la grande maison → les grandes maisons
✏️ Activité guidée : « tout le monde s'accorde ». Je donne un GN au singulier, tu le mets au pluriel à voix haute : le petit chat, une belle fleur, mon nouvel ami.

Exercices — mets le GN au pluriel

  1. un chat gris → ___
  2. la grande fille → ___
  3. mon beau jardin → ___
  4. une histoire drôle → ___
Voir le corrigé

1. des chats gris 2. les grandes filles 3. mes beaux jardins 4. des histoires drôles.

▶ Pratique : sujet « Le groupe du nom »

8 🔤 La phrase

🎯 Objectif : reconnaître une phrase bien formée, la mettre à la forme négative, et choisir la bonne ponctuation finale.

La règle

Une phrase commence par une majuscule et finit par un point : . (déclarative), ? (question) ou ! (exclamation). La forme négative encadre le verbe : ne … pas. Mots interrogatifs : qui, que, où, quand, comment, pourquoi.

Au tableau

Je joue dehors. → Je ne joue pas dehors.
Où vas-tu? · Quelle belle journée!
✏️ Activité guidée : je dis une phrase positive, tu la rends négative. Puis on transforme une phrase en question.

Exercices

  1. Mets à la forme négative : « Il aime les épinards. »
  2. Quelle ponctuation ? a) Tu viens___ b) Bravo___ c) Il pleut___
  3. Complète avec un mot interrogatif : « ___ pleures-tu ? » (on demande la raison)
Voir le corrigé

1. Il n'aime pas les épinards. 2. a) ? b) ! c) . 3. Pourquoi.

▶ Pratique : sujet « La phrase »

9 🧑‍🏫 Le sujet & l'accord du verbe

🎯 Objectif : trouver le sujet (« Qui est-ce qui… ? ») et accorder le verbe avec lui.

La règle

Le sujet fait l'action. On le trouve en demandant « Qui est-ce qui + verbe ? ». Le verbe s'accorde avec le sujet : nous → -ons, vous → -ez, ils/elles → -ent.

Au tableau

Les oiseaux volent. (Qui vole ? Les oiseaux → ils → -ent)
Nous aimons l'école. · Tu finis ton repas.
✏️ Activité guidée : dans 3 phrases, encadre le sujet et souligne le verbe. Vérifie qu'ils s'accordent.

Exercices — accorde le verbe (présent)

  1. Les enfants (jouer) ___ dans la cour.
  2. Nous (aimer) ___ les histoires.
  3. Tu (finir) ___ tes devoirs.
  4. Trouve le sujet : « Chaque matin, mon frère mange une pomme. »
Voir le corrigé

1. jouent 2. aimons 3. finis 4. sujet = mon frère.

▶ Pratique : sujet « Sujet & verbe »

10 ⏱️ Le présent de l'indicatif

🎯 Objectif : comprendre radical + terminaison, et conjuguer au présent aimer, finir, avoir, être, aller.

La règle

L'infinitif est le verbe non conjugué (aimer). On sépare le radical (aim-) et la terminaison (-er). Au présent, seule la terminaison change selon la personne.
aimerfiniravoirêtrealler
je/j'aimefinisaisuisvais
tuaimesfinisasesvas
il/elleaimefinitaestva
nousaimonsfinissonsavonssommesallons
vousaimezfinissezavezêtesallez
ils/ellesaimentfinissentontsontvont
✏️ Activité guidée : « la roue des personnes ». Je dis un pronom, tu conjugues aimer au présent. Puis on recommence avec être.

Exercices — présent

  1. je (aimer) ___
  2. vous (finir) ___
  3. il (avoir) ___
  4. nous (être) ___
  5. ils (aller) ___
Voir le corrigé

1. j'aime 2. finissez 3. a 4. sommes 5. vont.

▶ Pratique : sujet « Le présent »

11 📅 L'imparfait & le futur

🎯 Objectif : situer une action dans le temps et conjuguer à l'imparfait, au futur simple et au futur proche.

La règle

Imparfait (le passé qui durait) : -ais, -ais, -ait, -ions, -iez, -aient. Futur simple (plus tard) : -rai, -ras, -ra, -rons, -rez, -ront. Futur proche (bientôt) = aller au présent + infinitif : « Je vais manger. »
aimer (imparfait)aimer (futur)être (imparfait)être (futur)
je/j'aimaisaimeraiétaisserai
tuaimaisaimerasétaisseras
ilaimaitaimeraétaitsera
nousaimionsaimeronsétionsserons
vousaimiezaimerezétiezserez
ilsaimaientaimerontétaientseront
✏️ Activité guidée : je donne une phrase au présent, tu la mets à l'imparfait, puis au futur. Ex. « Je joue. » → « Je jouais. » → « Je jouerai. »

Exercices

  1. Imparfait : j' (aimer) ___
  2. Imparfait : nous (être) ___
  3. Futur simple : tu (aimer) ___
  4. Futur simple : ils (être) ___
  5. Futur proche : « Je ___ (aller + partir). »
Voir le corrigé

1. j'aimais 2. étions 3. aimeras 4. seront 5. Je vais partir.

▶ Pratique : sujet « Imparfait & futur »

12 💫 Le conditionnel & le participe présent

🎯 Objectif : conjuguer au conditionnel présent (ce qui pourrait arriver) et former le participe présent (en -ant).

La règle

Conditionnel présent : -rais, -rais, -rait, -rions, -riez, -raient. On l'emploie pour la politesse et l'hypothèse : « J'aimerais un jus. »
Participe présent : radical + -ant (aimer → aimant, finir → finissant, aller → allant). On dit souvent « en + participe présent » : en marchant.

Au tableau

Conditionnel : j'aimerais · nous serions · tu voudrais
Participe présent : chanter → chantant · finir → finissant
✏️ Activité guidée : transforme en participe présent : jouer, manger, courir (→ courant), lire (→ lisant).

Exercices

  1. Conditionnel : j' (aimer) ___ un dessert.
  2. Conditionnel : nous (être) ___ contents.
  3. Participe présent : finir → ___
  4. Participe présent : aller → ___
Voir le corrigé

1. j'aimerais 2. serions 3. finissant 4. allant.

▶ Pratique : sujet « Conditionnel & p. présent »

13 🔊 Les homophones

🎯 Objectif : choisir le bon homophone grâce au test de remplacement.

La règle — le test de remplacement

MotsAstuce
a / àSi on peut dire avait → a (verbe avoir). Sinon → à (lieu, direction).
et / estSi on peut dire était → est (verbe être). Si on peut dire « et… aussi » → et.
on / ontSi on peut dire avaient → ont (verbe avoir). Sinon → on (comme « il »).
son / sontSi on peut dire étaient → sont (verbe être). Sinon → son (à lui).
ou / oùoù (accent) = un lieu. ou = « ou bien ».
✏️ Activité guidée : je lis une phrase à trou, tu appliques le test à voix haute avant de choisir.

Exercices — choisis

  1. Il ___ content. (a / à / est)
  2. Je vais ___ l'école. (a / à)
  3. Ils ___ des jouets. (on / ont)
  4. Mes amis ___ gentils. (son / sont)
  5. Tu viens ___ tu restes ? (ou / où)
Voir le corrigé

1. est 2. à 3. ont 4. sont 5. ou.

▶ Pratique : sujet « Les homophones »

14 📖 Le vocabulaire

🎯 Objectif : synonymes, familles de mots, et ordre alphabétique pour le dictionnaire.

La règle

Un synonyme est un mot de sens proche (content ≈ heureux). Une famille de mots partage une même base (dent → dentiste, dentaire). Dans le dictionnaire, les mots sont classés par ordre alphabétique (a, b, c… puis 2ᵉ lettre, 3ᵉ lettre…).
✏️ Activité guidée : trouve 2 synonymes de « content ». Trouve 3 mots de la famille de « terre ». Range en ordre : chien, chat, cheval.

Exercices

  1. Synonyme de « rapide » : ___
  2. Un mot de la famille de « dent » : ___
  3. Range en ordre alphabétique : pomme, banane, orange.
  4. Quel mot vient en premier : « chat » ou « cheval » ?
Voir le corrigé

1. vite (ou véloce) 2. dentiste / dentaire / dentier 3. banane, orange, pomme 4. chat (cha… avant che…).

▶ Pratique : sujet « Le vocabulaire »

15 ✏️ Petits pièges (règles de position)

🎯 Objectif : maîtriser les lettres muettes, l'apostrophe, « m » devant b/m/p, la virgule dans une liste et le son [s].

La règle

Lettres muettes : lettres écrites mais non prononcées (le -d de grand, le -t de chat). Apostrophe : devant une voyelle, le/la/je deviennent l'/j' (l'ami, j'aime). Devant b, m, p, on écrit m au lieu de n (tomber, emmener, important). Virgule : sépare les éléments d'une énumération. Son [s] : « c » devant e/i se dit [s] (cerise) ; devant a/o/u il se dit [k] (carotte).
✏️ Activité guidée : trouve la lettre muette dans : petit, grand, souris, tapis. Ajoute l'apostrophe : « le arbre », « je aime ».

Exercices

  1. Corrige : « le école » → ___
  2. Corrige : « je habite » → ___
  3. n ou m ? « to___ber », « i___portant »
  4. Ajoute les virgules : « J'ai un chien un chat et un lapin. »
  5. « c » se dit [s] ou [k] ? a) cerise b) carotte
Voir le corrigé

1. l'école 2. j'habite 3. tomber, important (m devant b et p) 4. J'ai un chien, un chat et un lapin. 5. a) [s] b) [k].

▶ Pratique : sujet « Petits pièges »
